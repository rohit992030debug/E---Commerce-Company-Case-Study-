# 📊 E-Commerce Analytics Case Study | SQL + Power BI

## 🧾 Overview
This project is an end-to-end **E-Commerce Analytics Case Study** designed to extract meaningful business insights from transactional data.

The analysis focuses on:
- Customer behavior
- Product performance
- Sales trends
- Revenue generation
- Geographic distribution of customers

The project demonstrates how raw data can be transformed into **actionable insights** for decision-making in an e-commerce business.

---

## 🎯 Business Objectives
- Identify **high-value customers** based on total spending  
- Detect **repeat customers** to understand retention  
- Analyze **top-selling and low-demand products**  
- Track **monthly and daily sales trends**  
- Identify **top cities** for targeted marketing and logistics  

📊 Dashboard Insights:
Total Sales: 18M+
Total Quantity Sold: 925+ units
Top-performing product categories identified
Seasonal trends clearly visible in monthly analysis
